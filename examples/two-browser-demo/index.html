Control one browser from another without sending video.

The target owns the scene. The controller sends scoped commands, and the target returns authoritative live state over the same duplex WebRTC connection.

Network and privacy options

Direct WebRTC peers can learn one another’s IP addresses. VDO.Ninja signaling, STUN, and possibly TURN are third-party infrastructure. A relay may add latency. Do not put secrets in room names or public labels.

Starting a target generates a room and a 192-bit secret if either field is empty. Share both values through a separate trusted channel.
