# BRSP repository agent entrypoint

Before planning, editing, testing, or publishing this repository, read every Markdown file in `docs/` in lexical order. The protocol specification, privacy boundary, and qualification claims are durable product contracts.

Never silently weaken explicit activation, mutual proof, least-authority scopes, message bounds, control/state separation, backpressure, freshness behavior, teardown, accessibility, or source/license provenance. If implementation and documentation disagree, stop and reconcile them deliberately.
